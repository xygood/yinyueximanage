## 一、小组编组规则

### 1.1 人数限制

| 课程类型 | 最少人数 | 最多人数 |
|---------|---------|---------|
| 钢琴     | 2人     | 5人     |
| 声乐     | 2人     | 5人     |
| 器乐     | 2人     | 8人     |

**代码位置**: `validateGroup()` 函数 (约第3366行)

```typescript
const maxStudents = ['钢琴', '声乐'].includes(courseType) ? 5 : 8;
if (groupStudents.length > maxStudents) {
  return { valid: false, message: `${courseType}课每组最多${maxStudents}人` };
}
if (groupStudents.length < 2) {
  return { valid: false, message: `${courseType}课每组至少2人` };
}
```

### 1.2 主项/副项组合规则

#### 普通班（student_type = 'general'）

| 组合方式 | 主项人数 | 副项人数 | 说明 |
|---------|---------|---------|------|
| 方式1   | 2人     | 0人     | 最多2个主项，不能有副项 |
| 方式2   | 1人     | ≤2人    | 1个主项时最多2个副项 |
| 方式3   | 0人     | ≤4人    | 全部副项时最多4人（普通乐器） |
| 方式4   | 0人     | ≤5人    | 全部副项时最多5人（双排键） |
| 方式5   | 0人     | ≤8人    | 全部副项时最多8人（古筝、葫芦丝、竹笛） |

**代码位置**: `validateGroup()` 函数 (约第3394-3465行)

```typescript
// 普通班规则：
// 1. 最多2个主项+0个副项
// 2. 最多1个主项+2个副项
// 3. 最多0个主项+4个副项（普通乐器）
// 4. 最多0个主项+5个副项（双排键）- 仅当当前课程是双排键时
// 5. 最多0个主项+8个副项（葫芦丝、竹笛、古筝）- 仅当当前课程是这些乐器时
// 
// 【重要】判断依据是当前课程类型，不是学生有什么副项！
// 例如：钢琴课不会因为学生有双排键副项就限制为5人
if (mainCourseStudents.length > 2) {
  return { valid: false, message: '普通班主项最多2人' };
}
if (mainCourseStudents.length === 2 && secondaryStudents.length > 0) {
  return { valid: false, message: '普通班2个主项时不能有副项' };
}
if (mainCourseStudents.length === 1 && secondaryStudents.length > 2) {
  return { valid: false, message: '普通班1个主项时最多2个副项' };
}
```

#### 专升本（student_type = 'upgrade'）

- 专升本学生**没有主项**，只有副项
- **小组总人数最多 2 人**（强制限制）
- 副项人数限制：
  - **古筝、葫芦丝、竹笛**：最多 **3人**
  - **其他专业**：最多 **2人**

**代码位置**: 
- `validateGroup()` 函数 (约第3510行)
- `validateCurrentGroup()` 函数 (约第8296行)
- `checkGroupSizeLimit()` 函数 (约第5386行)

```typescript
// 检查专升本人数限制
if (hasUpgrade) {
  // 专升本小组总人数最多2人（强制限制）
  if (groupStudents.length > 2) {
    return { valid: false, message: '专升本小组最多2人' };
  }
  
  // 检查是否为古筝、葫芦丝、竹笛专业（专升本这些专业副项最多3人）
  const largeGroupInstruments = ['古筝', '葫芦丝', '竹笛'];
  const isLargeGroupCourse = largeGroupInstruments.includes(courseType);
  
  if (isLargeGroupCourse) {
    // 古筝、葫芦丝、竹笛：专升本副项最多3人
    if (secondaryStudents.length > 3) {
      return { valid: false, message: `专升本${courseType}副项最多3人` };
    }
  } else {
    // 其他专业：专升本副项最多2人
    if (secondaryStudents.length > 2) {
      return { valid: false, message: '专升本最多2个副项' };
    }
  }
}
```

**添加学生时的检查**:
```typescript
// 检查专升本人数限制：专升本小组最多2人
const hasUpgradeStudent = groupStudents.some(s => getStudentClassType(s) === 'upgrade') || 
                          getStudentClassType(student) === 'upgrade';
if (hasUpgradeStudent) {

  }
}
```

## 二、排课冲突检测

### 2.1 冲突检测类型

| 冲突类型 | 检测内容 | 错误提示 |
|---------|---------|---------|
| 时段冲突 | 同一时间段已有课程安排 | "时段冲突：该时间段已有 X 门课程安排" |
| 教师冲突 | 教师在同一时间段已有其他课程 | "教师时间冲突：您在周X第X节已有 XXX 课程" |
| 学生冲突 | 学生在同一时间段已有其他课程 | "学生冲突：XXX 在周X第X节已有 XXX 课程" |
| 琴房冲突 | 琴房在同一时间段已被其他教师占用 | "琴房冲突：XXX 在周X第X节已被 XXX 占用" |
| 禁排时段 | 该时间段为禁排时间 | "禁排时段冲突：该时间段为禁排时间" |
| 周次范围 | 课程周次范围与已有课程重叠 | "课程周次冲突：该时间段与已有课程周次范围重叠" |
| 大课表冲突 | 与大课表时间冲突 | "大课表冲突：该时间段与大学大课表时间冲突" |

**代码位置**: `handleDrop()` 函数 (约第4446-4700行)

### 2.2 冲突检测顺序

1. 验证分组有效性
2. 检查时段冲突（已有课程）
3. 获取/创建课程
4. 检查琴房冲突
5. 检查学生冲突（跨教师）
6. 检查教师冲突（跨教师）
7. 检查禁排时段冲突
8. 检查周次范围冲突
9. 检查大课表冲突
10. 检查课时是否已排满
11. 创建排课记录

## 四、批量选择功能

### 4.1 选择模式

| 模式 | 说明 |
|-----|------|
| 单次选择 | 每次点击选择一个周次 |
| 批量选择 | 自动填充可用周次直到选满16节 |
| 范围选择 | 拖拽选择多个时段 |

### 4.2 批量选择逻辑

**课时要求**: 专业小课固定 **16课时**（16节次）

**16课时限制规则**:
- **强制限制**: 无论小组有几人，最多只能选择 **16个时段格子**
- **计算方式**: 按选择的时段格子数计算，不是按学生人数叠加
- **超出阻止**: 选择超过16个时段时，系统会阻止保存并提示错误

**代码位置**: `handleSaveSchedule()` 函数 (约第1440行)

```typescript
// 限制最多16节课时（按格子数计算，一组就是一个整体，不管几个人）
const MAX_SLOTS = 16;
if (selectedTimeSlots.length > MAX_SLOTS) {
  showToast('error', `已排课时不能超过 ${MAX_SLOTS} 节，当前选择了 ${selectedTimeSlots.length} 节，请取消部分选择`);
  return;
}
```

**自动填充规则**:
1. 从当前点击的周次开始
2. 自动跳过禁排周次
3. 自动跳过已选择的周次
4. 循环选择直到选满16节或遍历完所有可用周次

**代码位置**: 约第1194-1270行

```typescript
// 批量选择模式
const requiredWeeks = 16;  // 固定16课时
const remainingWeeks = Math.max(0, requiredWeeks - totalSelectedCount);

// 自动填充可用周次（自动跳过禁排周次）
for (let w = 1; w <= totalWeeks; w++) {
  if (alreadySelectedWeeks.has(w)) continue;
  if (isSlotAvailableSync(day, period, w)) {
    availableWeeks.push(w);
  }
}
```

### 4.3 时段可用性检查 `isSlotAvailableSync()`

检查内容:
1. 全周禁排周次检查
2. 专业大课禁排时间数据检查
3. 教师已排定时间检查
4. 教师专业大课/理论课检查

**代码位置**: 约第910-1100行

  id: string;
