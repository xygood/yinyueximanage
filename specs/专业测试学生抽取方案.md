## 3. 抽取算法

### 3.1 总体流程

抽取算法分为 **三个阶段、四轮调整**，确保结果满足所有约束条件：
```
阶段一：名额分配（确定各教师抽几人）
  → Hamilton法：26基础 + 71比例分配

阶段二：学生抽取（确定各教师抽到谁）
  → 第1轮（首轮抽取）：按教师学生数从小到大依次随机抽取
  → 第2轮（主副均衡）：释放全主/全副教师的学生，重新抽取确保类型均衡

阶段三：班级均衡（微调班级分布）
  → 第3轮（自动班级调整）：从目标教师名下替换目标班级的学生
  → 第4轮（手动微调）：审查各班级偏差，定向执行同类型替换
  
输出最终结果
```

### 3.2 核心约束与决策逻辑

本方案需同时满足以下约束条件，它们之间存在相互制约关系：

| 约束 | 优先级 | 说明 |
|:----|:-----:|:------|
| **教师全覆盖** | 最高 | 26位教师每人至少1人，不足1人则无意义 |
| **学生不重复** | 最高 | 每人只出现一次，硬性条件 |
| **总名额固定** | 最高 | 精确97人 |
| **主副项均衡** | 高 | 每位教师尽量同时有主项和副项学生 |
| **班级比例合理** | 中 | 各班级占比尽量接近，但以教师分配优先 |
| **教师名额比例** | 中 | 名额按教师名下学生数比例分配 |

约束间的关系推导：
- **教师全覆盖** + **学生不重复** ⇒ 抽取顺序需设计，避免小名额教师被抢空
- **主副项均衡** ⇒ 第2轮需释放重抽
- **班级均衡** ⇒ 第3轮可定向替换，"教师分配优先"

### 3.3 数据预处理（去重与唯一标识）

**问题**：原始数据中存在以下情况需要处理：
1. 2对学生同名同姓但不同班级（刘紫涵、王子涵），属于不同人
2. 每名学生在不同教师名下出现多次（1主项+2副项）

**规则**：
```
唯一键 = (教师姓名, 学生姓名, 班级)
去重：同名+同教师+同班级 → 保留第一条记录
  - 有主项行 → 保留第一个主项行
  - 无主项行（仅副项） → 保留第一个副项行
```

**口径定义**：
- **口径A**：教师名下所有不重复学生（主项+副项），用于计算名额分配比例
- 选择口径A的原因：口径A反映教师实际工作量，主项和副项学生都占用教师时间

### 3.4 名额分配算法（Hamilton法）

**为什么选Hamilton法？**
- 需要将97个名额精确分配到26位教师
- 每位教师至少1名基础名额
- Hamilton法（最大余数法）实现比例分配，剩余名额按余数大小依次分配

**计算步骤**：

| 步骤 | 计算 | 结果 |
|:----|:-----|:----:|
| 总名额 | 97 | - |
| 基础名额 | 26 × 1 | 26人 |
| 剩余名额 | 97 - 26 | 71人 |
| 分配基数 | 各教师名下学生数 | 877人（含跨教师重复） |
| 各教师比例 | 本人学生数 / 877 × 71 | 整数部分 + 余数 |
| 余数分配 | 按余数从大到小排序 | 依次补满至71人 |

### 3.5 第1轮：学生抽取（从小到大策略）

**为什么从小到大？**
- 一个学生对应3位教师，每位教师都可从名下学生中抽取
- 如果大名额教师先抽，可能将小名额教师（如邵荣仅3人）的全部学生抽走，导致小教师无学生可选
- 按**教师名下学生数升序**抽取，保证小教师先锁定自己的学生

**流程**：
```
1. 将26位教师按名下学生数升序排列
2. 初始化全局已选学生集合 S = ∅
3. 对每位教师 t（按排列顺序）：
   a. 教师 t 的可用学生 = t 名下学生 - S
   b. 从可用学生中随机抽取 need[t] 人
   c. 将抽中学生加入 S
4. 所有教师抽取完毕，结果共97人
```

**推论**：此策略确保每位教师至少能抽到需要的人数，不会出现"无学生可选"的情况。

### 3.6 第2轮：主副项均衡调整

**触发条件**：第1轮结果中，某教师抽到的学生全部为主项或全部为副项，但该教师名下两种类型都有（排除邵荣、周晓等仅单类型教师）

**重新抽取**：
```
1. 识别需重抽教师（全部为单类型但实际双类型都有）
2. 从结果中移除这些教师的学生，放回全局池
3. 重抽处理（按学生数从小到大）：
   如果教师名额 >= 2 且名下两种类型都有可用学生：
     先各取 1 名主项 + 1 名副项
     剩余名额从其余学生中随机补满
   否则：
     完全随机抽取
```

**例外说明**：
- 邵荣（3人全主项）、周晓（19人全副项）→ 名下只有单一类型，无法干预
- 王武若因班级调整导致主项被替换且名下无可用主项 → 从其他教师处调配或保留原主项学生

### 3.7 第3轮：自动班级均衡调整

**目的**：第1~2轮以教师分配优先，班级分布可能不均衡。第3轮自动检测偏多/偏少班级，通过定向替换进行微调。

**目标教师**：`['徐颖', '王武', '林琳', '吴玉敏', '杨柳']`
- 选择标准：名下学生数最多、班级覆盖最广，有足够的替换弹性

**算法**：
```
1. 计算各班级理想人数 = round(班级总人数 / 3)
2. 计算偏差 = 当前人数 - 理想人数
3. 识别偏多班级（偏差 ≥ +2）和偏少班级（偏差 ≤ -2）
4. 计算各偏少班级的缺口 = 理想人数 - 当前人数
5. 对每个偏多班级，遍历其盈余人数：
   a. 按缺口从大到小排序偏少班级
   b. 对每个偏少班级，遍历目标教师：
      - 在该教师名下的偏多班级中找可替换学生
      - 保护规则：如果该学生是该教师的最后一个主项或副项，跳过
      - 找该教师名下同一类型的偏少班级可用学生
      - 找到即执行替换，更新缺口计数
      - 偏多班级人数 -1，偏少班级缺口 -1
6. 重复直到所有班级偏差均在 ±2 以内
```

**约束条件**：
- 仅替换目标教师名下的学生
- 仅执行**同类型替换**（主项换主项、副项换副项），不改变教师的主副项结构
- 保护每位教师的最后一个主项或副项不被替换
- 不改变总名额（97人）
- 不引入重复学生

**效果**（对比调整前后的班级范围）：
```
调整前: 2301(46.2%), 2302(44.0%), 2402(17.2%)  → 范围 17.2%~46.2%
调整后: 所有班级 24.0%~38.5%                   → 范围大幅收窄
```

### 3.8 第4轮：最终手动验证与微调

**目的**：自动算法完成后，可能存在某些班级偏差正好处于临界值的情况，需要人工审查并微调。

**触发条件**：自动算法执行后，若仍有班级偏差较大，或用户对个别班级分布有特定要求。

**流程**：
```
1. 审查各班级偏差，识别仍不理想的班级对（偏多 vs 偏少）
2. 从指定教师（如徐颖、王武、林琳、吴玉敏、杨柳）名下查找替换方案：
   - 在偏多班级中标记该教师名下已选中的学生
   - 在偏少班级中查找该教师名下未选中的学生（同类型）
   - 验证替换后教师的主副项结构不被破坏
   - 执行同类型替换
3. 输出最终结果
```

**实例**（本次执行）：
```
调整①: 2302(-2人), 2502(+2人)
执行:
  杨柳: 李瑞奇(2302,副项) → 丁澳康(2502,副项)
  陈思仪: 陈琳熙(2302,主项) → 赵佳䶮(2502,主项)
效果: 2302(32.0%→24.0%), 2502(27.3%→33.3%)

调整②: 2301(-1人), 2401(-1人), 2302(+2人)
执行:
  王琴: 尹思源(2301,主项) → 尤曼多依(2302,主项)
  李馨荷: 冯好东(2401,副项) → 黄万颖(2302,副项)
效果: 2301(38.5%→34.6%), 2401(37.5%→34.4%), 2302(24.0%→32.0%)
```

```

  │     │   └─ 是 → 释放重抽，保证至少1名副项
  │     ├─ 头一轮该教师抽取均为"副项"且名下有主项？

  │     ├─ 偏少班级(偏差≤-2)？

  │         └─ 跳过
  │
  └─ 输出最终结果
        │
```
