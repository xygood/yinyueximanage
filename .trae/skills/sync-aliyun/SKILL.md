# 同步阿里云服务器技能

## 功能描述

该技能用于自动将本地修改的文件同步到阿里云服务器，确保服务器上的代码与本地代码保持一致。

## 执行流程

1. **检查本地修改**：检查本地git仓库中修改的文件
2. **构建前端代码**：如果有前端代码修改，重新构建前端
3. **上传修改文件**：将修改的源文件和构建文件上传到服务器
4. **重启服务**：重启服务器上的相关服务，应用更新

## 操作步骤

### 1. 检查本地修改
- 执行 `git status` 命令检查本地修改的文件
- 识别需要同步的文件

### 2. 构建前端代码
- 如果有前端代码修改，执行 `npm run build` 命令重新构建
- 确保构建成功，生成最新的前端文件

### 3. 上传修改文件
- 使用 `scp` 命令将修改的源文件上传到服务器
- 将构建的前端文件上传到服务器的 `dist` 目录

### 4. 重启服务
- 登录服务器，重启后端服务
- 确保服务正常运行

## 注意事项

- 确保本地环境已安装必要的依赖
- 确保服务器地址和登录信息正确
- 确保网络连接稳定

## 示例使用

当用户发出 "同步阿里云" 的指令时，执行以下操作：

1. 检查本地修改的文件
2. 构建前端代码
3. 上传修改文件到服务器
4. 重启服务器服务
5. 验证同步是否成功

## 依赖检查

- 本地需要安装 `git`、`npm`、`scp`
- 服务器需要运行 `pm2`、`nginx`

## 错误处理

- 如果构建失败，检查前端依赖是否完整
- 如果上传失败，检查网络连接和服务器登录信息
- 如果服务重启失败，检查服务配置和依赖
