# 禁排数据导入模块 - 完整技术文档

## 一、项目概述

### 1.1 功能说明
禁排数据导入模块用于从音乐排课系统备份文件中导入禁排时间数据，包括：
- 系统禁排时间（节假日、特殊日期等）
- 专业大课安排（劳动教育等）
- 通适大课安排

### 1.2 解决的问题
- 教师排课时无法看到其他页面设置的禁排时间
- 不同教师之间禁排数据不同步
- 排课冲突无法及时发现

### 1.3 核心特性
- 数据持久化存储在服务器数据库
- 所有教师共享同一数据源
- 支持按班级、周次、星期、原因筛选
- 管理员可导入、删除、清空数据

## 三、数据库设计

### 3.1 表结构

```sql
-- 导入的禁排时间表（与系统 blocked_slots 表独立）
CREATE TABLE imported_blocked_times (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    
    -- 学年学期
    academic_year TEXT NOT NULL,
    semester_label TEXT NOT NULL,
    
    -- 班级关联（JSONB 格式）
    class_associations JSONB NOT NULL DEFAULT '[]',
    
    -- 时间信息（解析后的数组，方便查询）
    weeks INTEGER[],
    day_of_week INTEGER,
    periods INTEGER[],
    
    -- 禁排原因/课程名称
    reason TEXT NOT NULL,
    
    -- 数据来源标识
    source_type TEXT NOT NULL,  -- 'system_blocked' | 'large_class'
    
    -- 专业大课特有字段
    course_name TEXT,
    teacher_name TEXT,  -- 关键字段！用于教师避开自己的大课
    location TEXT,
    
    -- 原始数据备份
    raw_data JSONB,
    
    -- 导入信息
    imported_by UUID,
    imported_at TIMESTAMP DEFAULT NOW(),
    
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

-- 创建索引
CREATE INDEX idx_imported_blocked_class ON imported_blocked_times USING GIN(class_associations);
CREATE INDEX idx_imported_blocked_year_semester ON imported_blocked_times(academic_year, semester_label);
CREATE INDEX idx_imported_blocked_weeks ON imported_blocked_times USING GIN(weeks);
CREATE INDEX idx_imported_blocked_teacher ON imported_blocked_times(teacher_name);
CREATE INDEX idx_imported_blocked_source ON imported_blocked_times(source_type);
```

### 3.2 字段说明

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | UUID | 主键 |
| academic_year | TEXT | 学年，如"2025-2026" |
| semester_label | TEXT | 学期，如"2025-2026-2" |
| class_associations | JSONB | 关联班级数组 |
| weeks | INTEGER[] | 周次数组，如[1,2,3,4] |
| day_of_week | INTEGER | 星期几（1-7）|
| periods | INTEGER[] | 节次数组 |
| reason | TEXT | 禁排原因 |
| source_type | TEXT | 数据来源：system_blocked/large_class |
| course_name | TEXT | 课程名称（专业大课）|
| teacher_name | TEXT | 教师姓名（关键字段）|
| location | TEXT | 上课地点 |
| raw_data | JSONB | 原始数据备份 |
| imported_by | UUID | 导入人ID |
| imported_at | TIMESTAMP | 导入时间 |

## 四、后端API文档

### 4.1 导入禁排数据

**接口**: `POST /api/import-blocked-times`

**功能**: 从备份文件导入禁排数据到数据库

**请求参数**:
```json
{
  "backup_data": {
    "data": {
      "blocked_slots": [...],
      "large_class_schedules": [...]
    }
  }
}
```

**响应**:
```json
{
  "success": true,
  "imported_count": 10,
  "message": "成功导入 10 条禁排数据"
}
```

### 4.2 获取禁排时间列表（分页）

**接口**: `GET /api/imported-blocked-times/list`

**功能**: 分页查询禁排时间列表，支持筛选

**查询参数**:
| 参数 | 类型 | 说明 |
|------|------|------|
| page | int | 页码，默认1 |
| page_size | int | 每页数量，默认20 |
| class_name | string | 班级名称筛选 |
| week | int | 周次筛选 |
| day_of_week | int | 星期筛选（1-7）|
| reason | string | 原因筛选（模糊查询）|

**响应**:
```json
{
  "success": true,
  "data": [...],
  "pagination": {
    "page": 1,
    "page_size": 20,
    "total_count": 100,
    "total_pages": 5
  }
}
```

### 4.3 获取禁排时间（全部）

**接口**: `GET /api/imported-blocked-times`

**功能**: 获取所有禁排时间（不分页）

**查询参数**:
| 参数 | 类型 | 说明 |
|------|------|------|
| class_name | string | 班级名称筛选 |
| teacher_name | string | 教师姓名筛选 |

### 4.4 删除单条禁排时间

**接口**: `DELETE /api/imported-blocked-times/<id>`

**功能**: 删除指定ID的禁排时间

**响应**:
```json
{
  "success": true,
  "message": "删除成功"
}
```

### 4.5 清空所有禁排时间

**接口**: `POST /api/imported-blocked-times/clear`

**功能**: 清空所有导入的禁排时间（谨慎使用）

**响应**:
```json
{
  "success": true,
  "message": "已清空所有禁排数据",
  "deleted_count": 100
}
```

```python
def convert_blocked_slot(slot):
    return {
        'academic_year': slot.get('academic_year', '2025-2026'),
        'semester_label': slot.get('semester_label', '2025-2026-2'),
        'class_associations': slot.get('class_associations', []),

        'course_name': None,
        'teacher_name': None,
        'location': None,

    }
```

```python
    return {

    }
```

### 6.3 周次解析

```python
def parse_week_range(week_range_str):
    """
    解析周次字符串
    输入: "3-4周; 1-2,5-9周; 17周"
    输出: [1, 2, 3, 4, 5, 6, 7, 8, 9, 17]
    """
    weeks = []
    parts = week_range_str.split(';')
    
    for part in parts:
        part = part.strip().replace('周', '')
        
        # 处理范围格式 "3-4"
        if '-' in part and ',' not in part:
            start, end = map(int, part.split('-'))
            weeks.extend(range(start, end + 1))
        # 处理逗号分隔 "1,2,5-9"
        elif ',' in part:
            for sub in part.split(','):
                if '-' in sub:
                    start, end = map(int, sub.split('-'))
                    weeks.extend(range(start, end + 1))
                else:
                    weeks.append(int(sub))
        # 单周
        else:
            weeks.append(int(part))
    
    return sorted(list(set(weeks)))
```

## 九、使用流程

### 9.1 管理员操作流程

1. **进入专业小课页面**
2. **上传备份文件**
   - 点击"选择备份文件"按钮
   - 选择音乐排课系统备份文件（JSON格式）
   - 系统自动解析并导入数据
3. **查看禁排时间列表**
   - 查看所有导入的禁排时间
   - 使用筛选功能查找特定数据
   - 可删除单条或清空所有数据

### 9.2 教师使用流程

1. **进入专业小课页面**
2. **系统自动加载禁排数据**
3. **时间网格显示禁排标记**
   - 红色背景：禁排时间
   - 橙色背景：教师自己的专业大课
4. **排课时自动避开禁排时间**

## 十、注意事项

### 10.1 数据安全
- 导入操作会保留原始数据备份（raw_data字段）
- 清空操作不可恢复，请谨慎使用
- 建议定期备份数据库

### 10.2 性能优化
- 使用数据库索引优化查询
- 分页显示大量数据
- 前端缓存禁排数据

### 10.3 权限控制
- 导入/删除/清空功能仅管理员可用
- 查看功能所有用户可用

## 十一、故障排查

### 11.1 常见问题

**Q: 导入失败**
- 检查文件格式是否为JSON
- 检查文件是否包含 blocked_slots 或 large_class_schedules 数据
- 查看浏览器控制台网络请求错误

**Q: 数据不显示**
- 检查后端服务是否正常运行
- 检查API接口是否可访问
- 检查数据库表是否创建

**Q: 筛选不生效**
- 检查筛选条件是否正确
- 检查数据格式是否匹配

### 11.2 调试方法

```bash
# 测试API接口
curl http://localhost:5000/api/imported-blocked-times/list
```
